# 健身助手 Pro

此資料夾可獨立上傳為一個 GitHub Pages 儲存庫。請保留全部檔案與資料夾：

- `index.html`
- `manifest.json`
- `service-worker.js`
- `music.mp3`
- `assets/gym-icon-1024.png`
- `assets/`
- `.nojekyll`

GitHub 儲存庫的 **Settings → Pages** 設為從 `main` 分支的根目錄部署。部署完成後，以：

`https://<你的帳號>.github.io/<儲存庫名稱>/`

開啟。iPhone Safari 開啟後選「分享 → 加入主畫面」，即可使用健身助手 App 圖示。
